설정 및 데이터 관리

현재 브라우저에 자동 저장됩니다. 다른 기기에서 이어서 쓰려면 백업 JSON 파일을 업로드하세요.

다른 기기에서 사용하기
① 백업 파일 다운로드 → ② HTML 파일 전달 → ③ 새 기기에서 HTML 열기 → ④ 백업 파일 업로드. 업로드한 데이터는 해당 브라우저에 저장됩니다.

HTML 파일만 공유하면 다른 사람은 빈 데이터로 시작할 수 있어요. 실제 데이터가 든 백업 파일은 개인정보를 확인한 뒤 공유하세요.

브라우저 데이터 삭제, 시크릿 모드, 다른 브라우저 사용 시 저장 내용이 사라지거나 분리될 수 있습니다. 중요한 정보는 정기적으로 백업해 주세요.
